# Mobile App — ShopMKT

Este diretório representa o app Flutter para Android e iOS.

## Funcionalidades planejadas

- Cadastro de cliente e profissional
- Busca por categorias de serviço
- Solicitação com descrição, fotos e endereço
- Acompanhamento de status em tempo real
- Chat interno entre cliente e profissional
- Histórico de atendimentos

## Como iniciar

1. Instale o Flutter no seu ambiente.
2. No terminal, execute:

```bash
flutter create .
flutter pub get
```

3. Desenvolva as telas principais:
   - `login`
   - `cadastro`
   - `home`
   - `solicitacao`
   - `acompanhar`
   - `chat`

4. Conecte o app à API backend em `backend/server.js`.

## Observação

O código do app ainda precisa ser desenvolvido. Este README serve como guia inicial para começar o projeto Flutter.
