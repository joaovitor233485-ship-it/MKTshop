# Web Admin — ShopMKT

Este diretório representa o painel administrativo em Angular.

## Funcionalidades planejadas

- Aprovar profissionais
- Gerenciar clientes e solicitações
- Criar e editar categorias
- Acompanhar serviços em tempo real
- Visualizar relatórios e estatísticas
- Gerenciar pagamentos e reclamações

## Como iniciar

1. Instale o Angular CLI globalmente:

```bash
npm install -g @angular/cli
```

2. Crie o projeto Angular neste diretório:

```bash
ng new . --directory .
```
```

3. Desenvolva os módulos de administração usando componentes:
   - `login`
   - `dashboard`
   - `profissionais`
   - `clientes`
   - `solicitacoes`
   - `relatorios`

4. Conecte o painel à API backend em `backend/server.js`.
